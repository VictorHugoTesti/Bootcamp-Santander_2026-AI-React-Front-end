

# 🧱 Passo 1: Defina o papel do Educador Financeiro

Nesta etapa, você vai  **descrever qual problema o Educador Financeiro Inteligente deve resolver e para quem ele será útil**.

## ✍️ O que fazer

Antes de escrever:

-   Quem usaria essa solução?
-   Qual dificuldade financeira essa pessoa enfrenta?
-   O que a IA deveria ensinar, recomendar ou organizar?

## 📋 Modelo para você adaptar

Copie o bloco abaixo no seu editor de texto e preencha os campos entre colchetes:

txtCopiar

```txt
Crie a ideia de um Educador Financeiro Inteligente voltado para [tipo de usuário].

O principal problema dessa pessoa é [problema financeiro].

A solução deve ajudar o usuário a [objetivo principal].

O sistema deve se comunicar de forma [tom da comunicação].

```

## ✨ Exemplo preenchido

Veja como ficaria o Modelo acima já preenchido em um caso real (use como referência, não copie literalmente):

txtCopiar

```txt
Crie a ideia de um Educador Financeiro Inteligente voltado para jovens universitários.

O principal problema dessa pessoa é gastar mais do que ganha no início do mês.

A solução deve ajudar o usuário a organizar gastos e criar metas simples de economia.

O sistema deve se comunicar de forma clara, amigável e prática.
```

# 🧱 Passo 2: Adicione recursos e experiências inteligentes

Nesta etapa, você vai  **adicionar funcionalidades, comportamentos e restrições para enriquecer a solução criada**.

## ✍️ O que fazer

Antes de escrever:

-   Quais recursos tornariam a experiência mais útil?
-   Como a IA pode personalizar dicas e respostas?
-   O que a solução não deve fazer?

## 📋 Modelo para você adaptar

Copie o bloco abaixo no seu editor de texto e preencha os campos entre colchetes:

txtCopiar

```txt
O Educador Financeiro Inteligente deve possuir os seguintes recursos:

1. [Funcionalidade principal]
2. [Funcionalidade secundária]
3. [Experiência personalizada]

A IA deve adaptar as recomendações com base em [tipo de informação do usuário].

Evite respostas [tipo de resposta que deve ser evitada].

As sugestões devem ser apresentadas no formato [formato esperado].

```

## ✨ Exemplo preenchido

Veja como ficaria o Modelo acima já preenchido em um caso real (use como referência, não copie literalmente):

txtCopiar

```txt
O Educador Financeiro Inteligente deve possuir os seguintes recursos:

1. Controle simples de gastos mensais
2. Simulação de metas de economia
3. Dicas personalizadas de acordo com o perfil do usuário

A IA deve adaptar as recomendações com base em renda mensal, idade e objetivos financeiros.

Evite respostas técnicas ou difíceis para iniciantes.

As sugestões devem ser apresentadas no formato de listas curtas e exemplos práticos.
```

# 🧱 Passo 3: Una as peças e refine sua proposta

Nesta etapa, você vai  **transformar todas as ideias anteriores em um único prompt estruturado para gerar insights do projeto final**.

## ✍️ O que fazer

Antes de escrever:

-   O prompt final deixa claro quem é o usuário e qual problema será resolvido?
-   As funcionalidades estão organizadas?
-   A IA recebeu instruções claras sobre comportamento, tom e formato das respostas?

## 📋 Modelo para você adaptar

Copie o bloco abaixo no seu editor de texto e preencha os campos entre colchetes:

txtCopiar

```txt
Atue como um especialista em educação financeira digital.

Crie a proposta de um Educador Financeiro Inteligente para [tipo de usuário].

O sistema deve ajudar o usuário a [objetivo principal].

As principais funcionalidades devem incluir:
- [funcionalidade 1]
- [funcionalidade 2]
- [funcionalidade 3]

A comunicação deve ser [tom desejado].

As respostas devem seguir o formato [formato esperado].

Evite [restrição ou comportamento indesejado].

Ao final, apresente sugestões criativas para transformar essa ideia em um projeto frontend interativo.

```

## ✨ Exemplo preenchido

Veja como ficaria o Modelo acima já preenchido em um caso real (use como referência, não copie literalmente):

txtCopiar

```txt
Atue como um especialista em educação financeira digital.

Crie a proposta de um Educador Financeiro Inteligente para jovens que estão começando a trabalhar.

O sistema deve ajudar o usuário a controlar gastos, criar metas de economia e aprender conceitos básicos de finanças.

As principais funcionalidades devem incluir:
- Painel simples de gastos
- Alertas de despesas exageradas
- Recomendações personalizadas de economia

A comunicação deve ser amigável e objetiva.

As respostas devem seguir o formato de listas práticas e exemplos do cotidiano.

Evite termos técnicos difíceis e respostas genéricas.

Ao final, apresente sugestões criativas para transformar essa ideia em um projeto frontend interativo.

```

## ☁️ Como entregar seu Desafio

Salve seu Prompt final em um arquivo

textCopiar

```text
.txt
```

ou

textCopiar

```text
.md
```

(no editor de sua preferência) e publique em um dos hosts aceitos pela DIO:

**Opção 1, Google Drive (mais simples):**

1.  Faça upload do arquivo no seu Google Drive.
2.  Clique com o botão direito sobre o arquivo e escolha  **Compartilhar**.
3.  Em  **Acesso geral**, selecione  **Qualquer pessoa com o link**.
4.  Copie o link e cole no campo de submissão da DIO.

**Opção 2, Git/GitHub (ótimo para praticar versionamento):**

1.  Crie uma conta gratuita no GitHub, caso ainda não tenha.
2.  Crie um repositório público (ex:
    
    textCopiar
    
    ```text
    meus-desafios-criativos
    ```
    
    ).
3.  Adicione seu arquivo
    
    textCopiar
    
    ```text
    .md
    ```
    
    ao repositório (pode ser pelo próprio site, em  **Add file > Upload files**).
4.  Abra o arquivo no GitHub e copie o link da página (URL do navegador).
5.  Cole o link no campo de submissão da DIO.
